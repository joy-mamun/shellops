# Configuration Guide — ShellOps

Complete reference for all configuration options.

## Configuration File Location

- **Default**: `./config/shellops.conf` (generated by setup wizard)
- **System**: `/var/log/shellops/shellops.conf` (after installation)
- **User**: `~/.shellops/config/shellops.conf` (user installation)

## How to View/Edit

```bash
# View current configuration
cat config/shellops.conf

# Edit configuration
vim config/shellops.conf

# View configuration with comments
cat config/shellops.conf.example
```

## Configuration Reference

### Feature Enablement

```bash
# Enable/disable individual features
FEATURE_USER_MONITOR=true        # User activity tracking
FEATURE_DISK_CLEANUP=true        # Disk analysis & cleanup
FEATURE_BACKUP=true              # Backup creation & scheduling
FEATURE_HEALTH_CHECK=true        # System monitoring
```

### User Monitoring

```bash
# When to mark user as idle (seconds)
# Default: 3600 (1 hour)
# Range: 60-86400 (1 minute to 24 hours)
USER_MONITOR_IDLE_THRESHOLD=3600

# Alert when root logs in
# Options: true, false
# Default: true
USER_MONITOR_ALERT_ROOT_LOGINS=true
```

### Disk Cleanup

```bash
# Minimum file size to report as "large" (bytes)
# Default: 104857600 (100 MB)
# Examples:
#   1048576         = 1 MB
#   52428800        = 50 MB
#   104857600       = 100 MB
#   1073741824      = 1 GB
#   5368709120      = 5 GB
DISK_CLEANUP_SIZE_THRESHOLD=104857600

# Default to dry-run mode (preview without changes)
# Options: true, false
# Default: true (recommended for learning)
DISK_CLEANUP_DRY_RUN=true

# Directories to clean (internal setting, see cleanup config)
DISK_CLEANUP_TEMP_DIRS=("/tmp" "/var/tmp" "/var/cache/apt")
```

### Backup Configuration

```bash
# Directories to backup (space-separated)
# Default: /home /etc
# Examples:
#   BACKUP_DIRS="/home /etc"
#   BACKUP_DIRS="/home /etc /opt /var/www"
#   BACKUP_DIRS="/root /home/users /opt/myapp"
BACKUP_DIRS="/home /etc"

# Number of backups to keep (older ones deleted automatically)
# Default: 10
# Range: 1-100
# Example: Keep last 5 backups
BACKUP_RETENTION_COUNT=10

# Compression format (affects speed and size)
# Options: gzip, bzip2, xz, none
# Default: gzip
# 
# Speed (fastest to slowest):
#   1. none
#   2. gzip
#   3. bzip2
#   4. xz (best compression)
BACKUP_COMPRESSION=gzip

# Cron schedule for automatic backups
# Format: "minute hour day month weekday" (cron format)
# Leave empty to manually create backups
# 
# Examples:
#   "0 2 * * *"     = Daily at 2:00 AM
#   "0 * * * *"     = Every hour at :00 minutes
#   "0 3 * * 0"     = Every Sunday at 3:00 AM
#   "0 4 1 * *"     = 1st of month at 4:00 AM
#   "30 3 * * 1-5"  = Weekdays at 3:30 AM
#   ""               = (disabled - no automatic backups)
BACKUP_SCHEDULE=""

# Enable automatic backups (set to true if BACKUP_SCHEDULE is set)
# Options: true, false
# Default: false
BACKUP_ENABLED=false
```

### Health Check Thresholds

```bash
# Alert if CPU usage exceeds X percent
# Default: 80
# Range: 1-100
HEALTH_CHECK_CPU_THRESHOLD=80

# Alert if memory usage exceeds X percent
# Default: 80
# Range: 1-100
HEALTH_CHECK_MEMORY_THRESHOLD=80

# Alert if disk usage exceeds X percent (for / filesystem)
# Default: 80
# Range: 1-100
HEALTH_CHECK_DISK_THRESHOLD=80
```

### Logging Configuration

```bash
# Log level (verbosity)
# Options: ERROR, WARN, INFO, DEBUG
# Default: INFO
# 
# ERROR   = Only errors
# WARN    = Errors + warnings
# INFO    = All info (default, recommended)
# DEBUG   = Verbose debugging info
LOG_LEVEL=INFO

# Enable/disable logging to file
# Options: true, false
# Default: true
ENABLE_LOGGING=true

# Log file location (set automatically based on permissions)
# Usually: /var/log/shellops/shellops.log
# Fallback: ~/.shellops/logs/shellops.log
LOG_FILE="/var/log/shellops/shellops.log"
```

## Configuration Examples

### Example 1: Minimal Setup (Learning)

```bash
# Enable only the basics
FEATURE_USER_MONITOR=true
FEATURE_DISK_CLEANUP=true
FEATURE_BACKUP=false          # Don't backup yet
FEATURE_HEALTH_CHECK=true

# Conservative thresholds
USER_MONITOR_IDLE_THRESHOLD=7200    # 2 hours
DISK_CLEANUP_SIZE_THRESHOLD=524288000  # 500 MB
HEALTH_CHECK_CPU_THRESHOLD=90
HEALTH_CHECK_MEMORY_THRESHOLD=90
HEALTH_CHECK_DISK_THRESHOLD=90

# Preview mode (safe)
DISK_CLEANUP_DRY_RUN=true
```

### Example 2: Production Server

```bash
# All features enabled
FEATURE_USER_MONITOR=true
FEATURE_DISK_CLEANUP=true
FEATURE_BACKUP=true
FEATURE_HEALTH_CHECK=true

# Strict monitoring
USER_MONITOR_IDLE_THRESHOLD=1800     # 30 minutes
USER_MONITOR_ALERT_ROOT_LOGINS=true

# Daily backup at 2 AM
BACKUP_DIRS="/home /etc /opt /var/www"
BACKUP_RETENTION_COUNT=30            # Keep 30 days
BACKUP_COMPRESSION=gzip
BACKUP_SCHEDULE="0 2 * * *"          # Daily 2 AM
BACKUP_ENABLED=true

# Tight thresholds
HEALTH_CHECK_CPU_THRESHOLD=75
HEALTH_CHECK_MEMORY_THRESHOLD=85
HEALTH_CHECK_DISK_THRESHOLD=80

# Detailed logging
LOG_LEVEL=INFO
ENABLE_LOGGING=true
```

### Example 3: Maintenance Server

```bash
# Focused on cleanup and backups
FEATURE_USER_MONITOR=false
FEATURE_DISK_CLEANUP=true            # Aggressive cleanup
FEATURE_BACKUP=true                  # Backups are important
FEATURE_HEALTH_CHECK=true

# Aggressive cleanup settings
DISK_CLEANUP_SIZE_THRESHOLD=52428800  # 50 MB threshold
DISK_CLEANUP_DRY_RUN=false            # Actually clean

# Weekly backup at 11 PM Sunday
BACKUP_DIRS="/var/www /data"
BACKUP_SCHEDULE="0 23 * * 0"          # Weekly
BACKUP_COMPRESSION=bzip2              # Better compression
BACKUP_RETENTION_COUNT=52              # Keep 1 year

# Relaxed thresholds
HEALTH_CHECK_CPU_THRESHOLD=80
HEALTH_CHECK_MEMORY_THRESHOLD=85
```

## Editing Configuration

```bash
# 1. Open in editor
vim config/shellops.conf

# 2. Edit values
BACKUP_SCHEDULE="0 3 * * *"           # Daily at 3 AM
HEALTH_CHECK_CPU_THRESHOLD=75         # Stricter threshold

# 3. Save and exit (vim: :wq)

# 4. Verify
cat config/shellops.conf | grep BACKUP_SCHEDULE

# 5. Changes take effect immediately on next run
./shellops health
```

## Common Configuration Tasks

### Backup Different Directories

```bash
# Edit config
vim config/shellops.conf

# Change BACKUP_DIRS
BACKUP_DIRS="/home/important /opt/myapp /data"

# Test
./shellops backup test
```

### Increase Monitoring Alert Thresholds

```bash
# For dev/test system with variable load
vim config/shellops.conf

HEALTH_CHECK_CPU_THRESHOLD=95
HEALTH_CHECK_MEMORY_THRESHOLD=95
```

### Enable Compression for Backups

```bash
vim config/shellops.conf

# Use better compression (slower)
BACKUP_COMPRESSION=bzip2

# Next backup will use this compression
./shellops backup create
```

### Change Backup Schedule

```bash
vim config/shellops.conf

# Change from daily to weekly
BACKUP_SCHEDULE="0 3 * * 0"   # Weekly Sunday 3 AM
BACKUP_ENABLED=true

# Verify in cron
crontab -l | grep shellops
```

## Troubleshooting Configuration

### Configuration not taking effect

1. Check file is saved: `cat config/shellops.conf`
2. Verify syntax is correct (no typos)
3. Check for multiple config files in PATH
4. Run `./test.sh` to validate

### Invalid configuration values

ShellOps will:
1. Try to validate on startup
2. Use defaults for invalid values
3. Warn you in logs
4. Continue with safe values

Example:
```bash
HEALTH_CHECK_CPU_THRESHOLD=150   # Invalid, out of range 1-100
# ShellOps logs: "Invalid value, using default: 80"
```

### Permission denied when writing logs

```bash
# ShellOps will automatically fallback to user directory
# Logs go to: ~/.shellops/logs/shellops.log
cat ~/.shellops/logs/shellops.log
```
